## 📊 Gender Stereotypes Analysis (R)

### 📝 Overview
This project explores **gender stereotypes** using data from the international  
**Towards Gender Harmony** study.  
The analysis focuses on how **sensitivity** and **competitiveness** are perceived in women and men across different demographic and cultural contexts.

The results are presented as an **R Markdown HTML report**.

---

### 📂 Data
- **Source:** Towards Gender Harmony (open-access)
- **Observations:** 33,313
- **Countries:** 62
- **Years:** 2018–2020  
- **Dataset:** https://osf.io/trkyc/files/w6bt3

---

### 🎯 Research Focus
- Perception of **sensitivity** and **competitiveness** by gender  
- **Cross-cultural** differences  
- Differences by **field of study** and selected demographics  
- Relationships between sensitivity and competitiveness
